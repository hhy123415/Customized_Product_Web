# 台球杆定制计价标准与逻辑库

本知识库定义了台球杆的基础价格、规格变动补差价规则以及配件升级费用。

## 1. 基础产品信息 (Standard Specifications)
* **产品名称**：基础杆体（标准款）
* **基础价格**：1880 元
* **标准长度**：147 cm
* **标准重量**：19 oz

## 2. 规格定制补差价规则 (Adjustment Rules)
当客户要求的规格偏离标准值时，需按照以下逻辑计算差价：

### 2.1 长度调整 (Length Adjustment)
* **标准基准**：147 cm
* **计算规则**：每增加或减少 1 cm，价格相应增加或减少 **26 元**。
* **计算公式**：`长度差价 = (实际长度 - 147) * 26`

### 2.2 重量调整 (Weight Adjustment)
* **标准基准**：19 oz
* **计算规则**：每增加或减少 1 oz，价格相应增加或减少 **80 元**。
* **计算公式**：`重量差价 = (实际重量 - 19) * 80`

## 3. 可选升级配件 (Optional Upgrades)
客户可以选择以下配件或工艺，费用在基础价格之上累加：

| 项目 | 选项内容 | 附加费用 |
| :--- | :--- | :--- |
| **接牙** | 钛合金接牙 | +320 元 |
| **握把** | 真皮握把 | +280 元 |
| **涂装** | 特殊涂装（非磨砂碳纹） | +260 元 |
| **球杆盒** | 专业硬盒 | +460 元 |

## 4. 总价计算公式 (Calculation Logic)
AI 在回答用户询价时，请务必参考以下综合公式：
**总价格 = 基础价格(1880) + 长度差价 + 重量差价 + 所有选配附件费用**

## 5. 计价示例 (Examples for AI Reference)

**案例 A（标准定制）：**
* 用户需求：标准长度，标准重量，只要加一个真皮握把。
* 计算过程：1880 (基础) + 280 (真皮握把) = 2160 元。

**案例 B（非标定制）：**
* 用户需求：长度 150cm，重量 20oz，钛合金接牙，专业硬盒。
* 计算过程：
  1. 基础价格：1880 元
  2. 长度补差：(150-147) * 26 = +78 元
  3. 重量补差：(20-19) * 80 = +80 元
  4. 选配费用：320 (接牙) + 460 (硬盒) = 780 元
  5. 总计：1880 + 78 + 80 + 780 = 2818 元。
